# Personal Portfolio Site

A single-page resume/portfolio site linking out to the GitHub projects in this portfolio. Pure HTML/CSS, no build step, no dependencies.

## Customizing

Everything is in `index.html` -- swap the copy in the About/Skills sections, and add/remove entries in the Projects grid as your GitHub profile grows.

## Deploying

Works as-is on GitHub Pages, Netlify, Vercel, or any static host. For GitHub Pages: repo Settings -> Pages -> Deploy from branch -> `main` / root.
